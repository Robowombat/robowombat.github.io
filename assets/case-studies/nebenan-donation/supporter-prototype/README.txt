Fördermitglied werden – interactive mobile prototype
====================================================

How to open
-----------
Unzip the folder and open index.html in Chrome or Safari (double-click is fine).
Keep index.html and the "assets" folder together, or the images won't show.
An internet connection is needed for the Inter and Open Sans fonts (Google Fonts).

What you can try
----------------
- Monatlich / Jährlich toggle, amount tiles (10 € / 50 € preselected)
- Price field: tap to open the number keypad; Done checks the minimum
  (1 € monthly, 12 € yearly) and shows the error state below that
- "Unterstützen": opens the payment sheet; it confirms by itself after 2 seconds
  (or tap it), then shows the thank-you screen and returns to the start
- "Einmalig fördern?": opens the one-time support page

Notes
-----
- Built from the Figma file "Förderer in Product" and the Product Design System.
- The payment sheet is a draft built on Apple's iOS 27 kit; its rows
  (card, contact) are placeholders.
- AI-assisted prototype (Claude). Please review before sharing externally.
